# Producto

## 1. Identificación del producto

**Nombre:** Jaguar Retail System

**Tipo:** Sistema de gestión de inventario y ventas.

## 2. Propuesta de Valor

> **"Un Sistema Integral POS diseñado específicamente para la estructura interna de la UADY, que centraliza el control de inventarios de múltiples campus y automatiza el flujo de cobranza institucional."**

**Diferenciador principal frente a software comercial:**
La integración nativa del método de pago universitario. A diferencia de un POS genérico, este sistema procesa transacciones con Interuady, despliega un formulario obligatorio para capturar la dependencia y responsable del pago, y envía automáticamente estas operaciones a un módulo central de Cuentas por Cobrar.

**Necesidad que resuelve:**
Elimina discrepancias de mercancía mediante un control de existencias separado por bodega que actualiza de forma simultánea el stock global y local, agilizando la operación física con lectura predictiva de códigos de barras y emisión de recibos en impresora térmica.

## 3. Objetivo del producto

Desarrollar un sistema que permita centralizar y gestionar los procesos de
inventario y venta, proporcionando información actualizada sobre productos,
existencias y operaciones comerciales.

## 4. Usuarios del sistema

El sistema contempla diferentes tipos de usuarios y roles, entre ellos:

- Administrador Central (CDU)
- Ventas CDU
- Ventas Sociales
- Ventas Matemáticas
- Usuarios relacionados con las operaciones de venta y administración.

## 5. Alcance del producto

El producto contempla inicialmente los siguientes ámbitos:

- Gestión de inventario y catálogo.
- Punto de venta físico (POS).
- E-commerce y pasarela virtual.
- BOPIS y cuentas por cobrar.
- Requisitos transversales de rendimiento, disponibilidad, seguridad y
  arquitectura.

## 6. Funcionalidades principales

Entre las funcionalidades identificadas se encuentran:

- Gestión de productos.
- Control de existencias por almacén.
- Generación de códigos de barras.
- Consulta y actualización de inventario.
- Procesamiento de ventas.
- Procesamiento de pagos.
- Integración con lectores de códigos de barras.
- Gestión de cuentas por cobrar.
- Catálogo web.
- Carrito de compras.
- Procesos de recolección de pedidos.

## 7. Fuera de alcance

Las funcionalidades cuyo alcance todavía se encuentra pendiente de validación
con el cliente deberán considerarse provisionales hasta obtener dicha
confirmación.

## 8. Estado actual del producto

El proyecto se encuentra en una etapa inicial de análisis y diseño. Actualmente
se trabaja en la definición de requisitos, priorización, modelado del sistema
y organización de la documentación del proyecto.
