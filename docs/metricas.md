# Métrica de contribución individual

Durante las reuniones del equipo se identifican y distribuyen las actividades
necesarias para el desarrollo de **Jaguar Retail System**.

Para esta primera revisión no se establece una fecha límite específica para cada
actividad, debido a que el equipo se encuentra en una etapa inicial de
organización y definición del proyecto.

## Método de estimación

Para estimar el esfuerzo de cada actividad se utiliza un método basado en el
tamaño de la tarea. El tamaño representa la dificultad y el esfuerzo aproximado
requerido para completarla.

| Tamaño | Dificultad |
|---:|---|
| 1 | Normal |
| 3 | Media |
| 5 | Alta |

Un valor mayor representa una actividad que requiere mayor esfuerzo, análisis,
diseño o tiempo de ejecución.
