# Jaguar Retail System

Sistema de software orientado a la gestión de inventario, ventas y procesos
comerciales relacionados.

---

## Descripción

Jaguar Retail System tiene como objetivo centralizar y gestionar los procesos
de inventario y venta, proporcionando información actualizada sobre productos,
existencias y operaciones comerciales.

Actualmente el proyecto se encuentra en la etapa de análisis y diseño,
trabajando en la definición de requisitos, priorización, modelado y
organización de la documentación.
